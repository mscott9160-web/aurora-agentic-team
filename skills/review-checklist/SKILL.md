# Review Checklist

Review the diff and relevant surrounding code. Report findings ordered by severity with evidence, impact, and a focused recommendation. Verify acceptance criteria, error handling, security and privacy implications, accessibility where relevant, test coverage, and unresolved risks. Do not edit product files.
