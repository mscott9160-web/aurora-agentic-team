# Definition of Done

A backlog item is done only when:

- The story has clear acceptance criteria and a named owner.
- The implementation satisfies the approved design and project rules.
- Appropriate automated and exploratory testing has produced evidence.
- Known defects, risks, and deferred work are recorded.
- QA reports a pass or the human owner explicitly accepts a conditional result.
- Review findings are resolved or explicitly accepted by a human.
- Release readiness has a rollback plan and human go/no-go approval.
